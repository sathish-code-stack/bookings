# Eventra – My Bookings

This project is a simple My Bookings section for Eventra, created using HTML, JavaScript, and Tailwind CSS.

### Features
- View booking details
- Filter bookings by status
- Cancel bookings
- Display booking count
- Responsive design

### Technologies Used
- HTML
- JavaScript
- Tailwind CSS

### Note
This is a frontend demo project with sample booking data. Booking changes are not saved to a database.
